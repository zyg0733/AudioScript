## 本轮发现的回归场景

- 更新安装和重启与会话启动共用原子占用；启动、采集和异步收尾期间拒绝安装或重启，失败或取消后释放占用。
- 安装和重启前等待偏好、悬浮窗以及其他设置写入；更新期间拒绝新的设置修改，同一设置键按提交顺序保存。
- 保存失败阻止继续更新或重启；正确保存后可重试，不丢失已经安装的版本状态。
- 悬浮窗配置、模式及显示状态保存失败时返回错误，并保留原内存状态；真实文件写入障碍及移除障碍后的重试均有回归覆盖。

上述修复由源代码和回归测试覆盖，已通过 PR #7 合入 `main` 并随 `v0.2.13` 发布；正式 `0.2.12` 升级到该版本的 GUI 验收见本文首节。既有 `v0.2.12` 发布文件保持不变。
