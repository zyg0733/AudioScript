# AudioScript 阶段迭代计划

更新：2026-10-30。上一轮基础能力已合入 main，本轮完成后发布 v0.3.0。

方向：本地优先的外语音视频理解助手。顺畅听懂 → 保存内容 → 整理摘录 → 回到原声。

## 阶段一：字幕体验（已完成）

会话状态与错误恢复、字幕重新同步、暂停跟随与回到最新、双语复制、长记录分页、及时字幕断句预设，以及失败译文重试。

## 阶段二：内容保存（已完成）

临时转写与手动/自动保存、退出收尾、启动恢复、最近记录、标题和来源维护、全文查找及删除。清空当前转写不会删除已存记录。

## 阶段三：修订与摘录（已完成）

原文和译文修订、不可变历史版本与恢复、版本检查、标记和笔记，以及 Markdown / SRT / VTT 全文或选段导出。书签可保留标记时的正文版本。

## 阶段四：导入与回听（已完成）

音视频和 SRT/VTT 导入、字幕关联媒体、本地资产管理、处理进度与取消、文字定位播放及片段回听。重新识别和译文精修生成派生记录。

## 内容复用（已完成本地版本）

个人术语维护、译后建议对照与逐段应用；原文摘取式章节和要点、带时间出处的关键词问答。以上均在本机处理。

当前边界：中英方向沿用本地模型；重新精修采用所选模型；媒体能否解码取决于系统 WebView，通用格式可转为 PCM16 WAV 导入。关键词问答提供原文证据，不生成无出处的答案。

## v0.3.0：从功能接通到持续使用

### 阶段一：可靠保存与编辑（已完成）

翻译模型不可用时保留已识别原文和媒体；损坏记录不阻断其余资料；修订和笔记草稿跨分页、筛选、页面保留；字幕导入保存原文语言，旧记录可补充语言后统一重译方向。语言改变后拒绝旧方向的迟到结果；明确选择的字幕与媒体允许来自不同目录；进度查询失败会自动重试。

### 阶段二：连续回听（已完成）

加入播放速度、片段循环、上次进度恢复，以及随播放更新的双语字幕。查阅和编辑正文时不强制抢走阅读位置。

### 阶段三：找到具体内容（已完成）

资料搜索展示命中的原文、译文或笔记及时间；点击命中直接打开对应段落。资料列表分批展示，保留原文、历史和导出完整内容。

三个阶段完成后统一提交，运行必要回归与 CI，推送并通过既有签名流程发布 v0.3.0。后续围绕真实使用反馈迭代，不另设日志、报告或文档阶段。
